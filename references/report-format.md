# 报告格式 v18 详解

## 6 段 AI 报告完整结构

### 一、持仓诊断 (≤ 400 字)
每只 ETF 1-2 句, 只列技术指标变化, 不做主观判断。

格式:
```
[[黄]]159516 半导体设备[[/黄]]: 5 日线走平未拐头, RSI 44 中性区间, MACD 绿柱连续 3 日收窄, 量能持续萎缩, 价格跌破 20 日线。🟡
```

3 色灯:
- 🟢 健康 = 5 指标 4-5 个健康
- 🟡 关注 = 5 指标 2-3 个健康
- 🔴 警惕 = 5 指标 0-1 个健康, 或极端 (浮亏 > 50%)

### 二、大盘环境 (≤ 250 字)
3 大指数 + 涨跌幅 + 成交额 + 锚点对比 (3800/4000/4190), 只列数据, 不加色。

格式:
```
上证 3946.68 距 4000 心理整数关仅 1.35%, 距 3800 政策底约 3.86%。创业板 3602.08 站稳 5 日线。A 股总成交 ¥21,524 亿, 较上一日缩量 14.69%。
```

### 三、板块产业逻辑 (≤ 300 字)
每板块 1 句话利空利好, 自动标板块名+ETF。

格式:
```
[[黄]]半导体设备[[/黄]]([[黄]]159516[[/黄]]): 国产替代逻辑未变, 但设备端短期受海外制裁传闻扰动。
[[黄]]科创芯片[[/黄]]([[黄]]588200[[/黄]]): AI 算力需求支撑, 景气度持续。
[[黄]]有色金属[[/黄]]([[黄]]516650[[/黄]]): 铜铝价格高位震荡, 美联储降息预期反复。
[[黄]]创业板[[/黄]]([[黄]]159915[[/黄]]): 成长风格占优, 新能源+生物医药权重企稳。
[[黄]]恒生科技[[/黄]]([[黄]]513260[[/黄]]): 港股流动性受美债利率压制, 缺乏催化剂。
```

### 四、科技/政策重大消息 (≤ 200 字)
基于 `batch_web_search` + `core/industry_news.py` 筛。
**整条消息核心内容** 用 `[[黄]]标黄` (LLM 决定)。

### 五、综合分析 (≤ 400 字)
4 维综合: 持仓诊断 + 大盘环境 + 板块产业逻辑 + 重大消息。
**只做分析结论**, 不重复 4 段已有内容。
**绝对禁止**: 加仓线/止损位/止盈位/趋势走坏位/加仓/止损/止盈/清仓 等主观判断词或关键位数字。
**只对重要判断结论** 用 `[[黄]]标黄` (LLM 决定)。

### 六、心理建设 (≤ 50 字)
1-2 句话, 根据整个报告结论, 安抚/坚定/当头棒喝。
**整段用 `[[黄]]...[[/黄]]` 包裹**。

## 标色机制 (v18 方案 2)

### 代码自动标 (1/3 段)
- 持仓诊断 / 板块产业逻辑段
- 关键词字典: `ETF_KEYWORDS` in `core/report.py`
- 优先匹配长串 (避免短词先匹配)
- 占位符保护已标黄内容, 避免嵌套

### LLM 输出标 (4/5/6 段)
- prompt 要求 LLM 输出 `[[黄]]...[[/黄]]` 标签
- 不强求, 漏标不报错
- `process_inline` 兼容 `[[橙]]` 旧标签

## 标黄数量预期 (main 账户, 5 只 ETF)

| 段 | 标黄数 | 备注 |
|---|---|---|
| 一、持仓诊断 | 5 | 5 只 ETF 全名 |
| 二、大盘环境 | 0 | 不加色 |
| 三、板块产业逻辑 | 10 | 5 板块 + 5 ETF |
| 四、重大消息 | 0-3 | 消息条数 |
| 五、综合分析 | 1-3 | 重要判断 |
| 六、心理建设 | 1 | 整段 |
| **合计** | 17-22 | |

## 渲染后处理

如果改 .md 后要重渲 AI 段:

```python
import re
from pathlib import Path
md = Path("docs/reports/daily-review-2026-08-12-main.md").read_text()
m = re.search(r"## 🤖 AI 分析(.+?)(?=---)", md, re.DOTALL)
ai_md = "## 🤖 AI 分析" + m.group(1)
from core.report import render_ai_html
ai_html = render_ai_html(ai_md)
html = Path("docs/reports/daily-review-2026-08-12-main.html").read_text()
new_html = re.sub(r'<div class="insight">.*?</div>', ai_html, html, count=1, flags=re.DOTALL)
Path("docs/reports/daily-review-2026-08-12-main.html").write_text(new_html)
```
